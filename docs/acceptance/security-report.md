# 五棋升级 · 安全报告（security-report.md）

## 范围与结论

五种棋类服务端权威校验全部实测（SEC-001 ✅）：
- 围棋：落子仅空点/禁自杀/提子计算/superko 均在服务端引擎；数子阶段指令（mark/score-confirm/score-resume）仅轮次方生效（集成实证：非轮次确认无效、恢复对弈后可继续）。
- 五子棋：占位/轮次/终局锁服务端判定（集成实证：终局后 f1 被拒、重复请求幂等不重复落谱）。
- 客户端无棋盘提交面（协议仅 from/to/promotion/path）（SEC-002 ✅）。

## 剩余风险

- SGF 导出为文本生成（无导入解析面）；若未来加导入需单独审计。
- 房间包仍合并全部引擎（体积问题非性能安全）；无其他新增攻击面。
