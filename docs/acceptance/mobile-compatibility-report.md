# 五棋升级 · 手机适配报告（mobile-compatibility-report.md）

## 1. 自适应实现（MOBILE-001~007/024）

- 布局：CSS Grid/Flexbox + 媒体查询（≤860px 纵向堆叠）；无 UA 嗅探（MOBILE-002）。
- 视口：`min-height: 100dvh`；`.room` 顶部/左右 `env(safe-area-inset-*)`；`.room-body/.home-main` 底部安全区 padding（MOBILE-004/005）。
- 棋盘尺寸：容器宽度驱动（SVG width:100%），`max-width: min(100%, calc(100dvh - 300px))` 防止高度溢出（MOBILE-008）；五棋棋盘 SVG 保持固有比例（跳棋六角/围棋交叉点均按 viewBox 等比缩放，MOBILE-011 ✅）。
- 自动完成，无设备模式选择（MOBILE-024 ✅）。

## 2. 视口矩阵实测（MOBILE-022）

11 视口 × 5 棋 = **55 项**：横向溢出 0、棋盘渲染可见 55/55。全量结果：five-games-viewport-matrix.txt。
抽样视口：360×740 / 360×800 / 375×812 / 390×844 / 393×852 / 402×874 / 430×932 / 768×1024 / 1024×768 / 1280×800 / 1440×900。
另：e2e 375×812 五棋专项（five-games.spec 移动用例）PASS。

## 3. 触控与命中（MOBILE-012~015）

- 高密度棋盘（围棋 19 路/五子棋 15 路）：命中半径=半格以上（19 路手机 360px 宽时 ≈17px 直径吸附区），点击吸附最近交叉点；视觉反馈=落子/上一手角标。
- 快速点击/双击：e2e 与浸泡覆盖重复请求路径（幂等）。
- 真机触控/软键盘遮挡/旋转重校准：**无真机，NOT_TESTED**（MOBILE-023 声明：浏览器模拟不能完全替代真机）；旋转后坐标为 SVG 视口内相对计算，理论上免校准，需真机复核。

## 4. 信息可读（MOBILE-019）

最近一步面板/上一手标记/对手提示在窄屏使用同一组件（LastMoveBar/toast），e2e 375 视口断言最近一步文本可见。
