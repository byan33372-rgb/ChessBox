# 缺陷清单（defects.md）

## 本轮发现并修复

### DEF-001（P1 · 规则缺陷 · 已修复 · 已回归）
- **标题**：中国跳棋起始营内互走被误禁，满营时后排骨棋子整局无法移动。
- **发现途径**：验收补测"4/6 人实际对局"集成用例（西南营开局步 `f13→g13` 营内互走被 ILLEGAL_MOVE 拒绝）；随后用引擎探针确认 `m15→m14`（同营相邻空位）同样被拒。
- **复现条件**：任意人数；对己方起始营内相邻空位发起普通移动（如 2 人局 b 方 `m15→m14`）。修复前返回 ILLEGAL_MOVE。
- **根因**：`src/games/checkers/engine.ts` 的 `campViolation` 只豁免"目标营地"（`camp !== myTarget` 即拒），未豁免己方**起始营地**——营内腾位移动全部被拒；营满时后排棋子的所有邻格均为己方棋子 → 后两排（含南尖）整局无法参与。前端 UI 纯函数 `checkersUi.campBlocked` 存在同源问题（会错误圈定可走目标）。
- **修复方案**：引擎与 UI 同源修改——落点营地属"己方起始营"或"己方目标营"均放行；他人营地仍禁入；"已进目标营地不得离开"规则保持不变。
- **回归测试**：
  - `tests/unit/checkers-engine.test.ts`：新增"起始营内移动（DEF-001）"3 项（满营尖子无路=正常规则；腾位后营内互走合法；出营/禁入他人营边界）。
  - `tests/integration/checkers-rooms.test.ts`：4 人局 a→b→c→d 实际对局轮转、6 人局 a→f 实际对局轮转（修复前均失败）。
  - 全量：vitest 150 + 57、e2e 18 全绿（修复后执行）。
- **状态**：CLOSED（提交 `2c7607d`）。

### DEF-002（P3 · 测试基建 · 已修复）
- **标题**：soak 浸泡脚本 requestId 短于服务端 schema 下限（8 位）导致全部走棋被 INVALID_INPUT 拒绝。
- **根因**：脚本生成 `sk-0-0`（6 位）；服务端 schema `^[A-Za-z0-9-]{8,64}$` 正确拒绝——服务端行为正确，脚本缺陷。
- **修复**：requestId 加固到 ≥8 位；重启浸泡后 0 错误。
- **状态**：CLOSED。
