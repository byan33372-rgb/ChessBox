## 2. 关键裁定（house rules / 版本选择）

| # | 项目 | 裁定 | 理由 |
| --- | --- | --- | --- |
| U1 | Passing Symbol 数量 | 平台标记 36 张（每色数字 1–9 的第 2 张）；官方说明书未列精确分布，在 CARD_CATALOG 标注为平台标记 | 任务书 §19.4 禁止伪造官方数量 |
| U2 | 自定义牌 | 预置安全模板 `next_player_draw3`（下家摸 3 并失去回合 + 出牌者选色）；服务端实现，无用户代码；开局前向全员公示 | 任务书 §19.3 安全约束 |
| U3 | Team Draw Four | 下家抽 4 并跳过，其队友抽 2（HXT58 字面版本）；3 人 2v1 孤立玩家被指向时不执行队友部分 | 任务书 §21.4 建议 |
| U4 | Team Play | 出牌者先选色；选色后跳转到队友回合（队友继续出牌） | 简化且确定 |
| U5 | 无队友的 Team Play/Team Draw Four | 退化为普通 wild（选色）/ 下家抽 4（无队友部分）；标记 degraded | 任务书 §21.6 |
| U6 | 开局起始牌 | 经典：+2 → 先手罚 2 跳过；反转 → 方向翻转；跳过 → 先手跳过；wild → 先手选色；+4 → 放回重翻。Teams：非数字牌一律插回重翻 | 任务书 §20.7 / §21.2 |
| U7 | 抽牌流程 | 有可出牌时也可选择抽 1；抽后不出则回合结束（不实现"抽后只能出刚抽的"细则——简化，在规则页明示） | 任务书允许 house rule |
| U8 | +4 质疑 | 出牌后进入质疑窗口，只有被指定的下家可响应；超时（当前无超时则 bot/玩家显式提交）视为不质疑 | 任务书 §20.6 |
| U9 | UNO 漏喊 | 剩 2 张时可喊（服务端校验手牌数）；出完剩 1 张未喊 → 任何玩家可抓（罚 2）；lastActor 只保留最近一次 | 任务书 §20.8 |
| U10 | Teams 出局/回归 | 出完者 isOut；队友手牌 ≥2 时传一半（向下取整，队友保留较大半）→ 回归者重新参与；队友 <2 张 → 不回归。两人均 0 → 队伍胜 | 任务书 §21.5 |
| U11 | Teams 交流限制 | 首版不实现聊天屏蔽（无队友私聊频道）；在规则页说明 | 简化 |
| U12 | 超过 2 人的队伍 | 首版不开放（仅 2v2 与 2v1）；3v1/1v1v1v1 不纳入 | 任务书 §21.6 建议 |
| U13 | 罚抽与叠加 | 不实现 +2/+4 叠加免除；罚抽由系统立即执行 | 任务书 §20.5 禁止叠加 |

## 3. 未实现/简化（如实标注）

- 未实现"抽到可出牌立即打出"的完整细则——抽后不出直接轮转（U7）。
- 未实现 UNO 挑战时的"向质疑者展示手牌"——质疑结果只公布成功/失败。
- 未实现累计 500 分制——首版单轮胜负，积分记录在 roundScores。
- Passing Symbol 的秘密同时提交——实现为服务端原子交换（双方 hand 中随机选），未做 UI 上"各自秘密选"——引擎用随机选取替代（防止 UI 泄露）。
