## 2. 数量口径

- 标准版 **108 张（含 4 EX）**；军争 **52 张**；合并 **160 张**。104/108 两种口径不混用（EX 单独打标 pack='ex'）。
- 军争篇基本牌逐张数：**火杀 5、雷杀 9、闪 9、桃 4、酒 5（=32）**——与任务书 §6.3 行文一致；初版测试曾按笔误写成火杀 6/闪 8，经附录 B 逐张复核后修正（附录 B 与 §6.3 完全一致，无冲突）。
- 合并计数：无懈可击 7（标准 4 + 军争 3）、闪 24、桃 12、杀 30、火杀 5、雷杀 9、酒 5。

## 3.1 引擎实现裁定的补充

- **仁王盾 vs 丈八蛇矛**：丈八视为的杀无花色 → 不触发仁王盾（无花色非黑色）。
- **寒冰剑**：普通杀伤害前询问来源；防止伤害改为弃目标 2 张牌（先随机手牌再装备；不足则有多少弃多少）。
- **麒麟弓**：造成伤害时可弃目标一匹坐骑（有 +1 先弃 +1）。
- **方天画戟**：仅当杀是最后一张手牌时可指定至多 3 个目标（与官方一致）。
- **青釭剑**：无视目标防具（仁王盾/八卦阵/藤甲/白银狮子对青釭杀不生效）——八卦阵判定是"使用闪的替代"，青釭剑不阻止其发动（裁定：青釭只影响防具被动效果）。
- **判定牌去向**：天妒（郭嘉判定）收入手牌；洛神黑色判定收入手牌；其余进入弃牌堆。鬼才可在任意判定生效前用手牌替换（替换牌成为判定牌）。

## 4. 已知未实现/简化（如实标注）

- 未实现「酒→下一杀伤害+1」与「酒重铸外的进阶用法」（H2）。
- 未实现观星「置底顺序自定」——置底保持抽取时的相对顺序。
- 贯石斧/流离的弃牌范围限手牌（H12/H21）。
- 反间展示牌后目标获得牌——若目标因伤害死亡，牌仍进入其遗牌（随死亡清理进弃牌堆）。
- 素材授权：无官方授权；武将/卡牌均为文字实现，无立绘/音效；对外发布前需完成商标与素材审查（任务书 §3.1）。
